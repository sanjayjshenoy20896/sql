Each table cell should contain a single value and 
each column must have a unique name
b.)Second Normal Form (2NF):

c.) Third Normal Form (3NF):
Every non key attribute must be independent of other non key attributes

Every Determinant (An Attribute that can determine other attributes) Must be Candidate key

it is like a reflex action which allows you to set up automatic action
Adding
Updating
Deleting

When does it run:
1.) INSERT: When new data is added to a table
2.) UPDATE:When existing data in table changes
3.) DELETE: When data is removed from a table

AFTER INSERT ON BorrowedBooks
