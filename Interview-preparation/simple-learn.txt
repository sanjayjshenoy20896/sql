5.) DELETE and TRUNCATE
They are both used to remove data from a table but work in different ways

TRUNCATE -> DDL
They are usedto delete all records in table
we cant rollback the data
it is auto command
It is a faster operation

DELETE -> DML
It is used to delete row level and table level data
We can initiate data rollback if we maintain Transaction
it is explicit committed
It is a slower operation

21.) Difference between where and having 
WHERE:
-> The clause specifies the criteria which records must meet to be selected in result set
It can be used without group by clause
-> It is used for select rows before grouping
-> It cannot contain aggregate functions
-> It is used to impose condition on select statement as well as single row functions.
eg: SELECT Column, AVG(Column_name) FROM table_name
WHERE Column > value 
GROUP BY column_name

having:
-> It cannot be used without a group by clause
-> It select one or more rows after grouping
-> It can contain aggregate functions
-> Used to impose condition on GROUP function and is used after group by clause

Syntax:
SELECT column_name
FROM table_name
WHERE condition
GROUP BY column_name
HAVING condition
ORDER BY condition

30.) Different types of join
